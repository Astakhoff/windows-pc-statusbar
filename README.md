# Windows PC Status Bar

PCStatusBar — планируемая компактная панель состояния компьютера для Windows с живыми показателями CPU, RAM и свободного места на C:.

**Статус:** создан начальный репозиторий с требованиями. Исходники приложения, установщик и готовая сборка пока отсутствуют.

## Возможности по заданию

- Общая загрузка CPU в процентах.
- Занятая физическая RAM: процент и занято / всего в GiB.
- Свободное место на C: в GiB и процентах.
- Независимые зелёный, жёлтый и красный статусы; серый цвет для недоступных данных.
- Настраиваемые пороги, задержки и гистерезис для спокойной смены цветов.
- Температуры CPU/GPU при наличии достоверных доступных датчиков.
- Русский интерфейс настроек, управление из трея, автозапуск для текущего пользователя.

## Размещение

Первая версия по заданию — отдельная тонкая Win32 AppBar непосредственно над штатной панелью задач. Она резервирует рабочую область выбранного монитора. Это дополнительная строка с показателями; закреплённый ярлык и значок трея служат для запуска и управления.

## Предполагаемый стек

C# + WinForms + поддерживаемая LTS-версия .NET, нативные Win32 API для метрик и AppBar. Точную версию SDK следует проверить перед реализацией.
